☕ Campus Café Website
📌 Project Overview
Campus Café is an interactive café website designed to showcase popular food and drink items, special offers, opening hours, and contact information in a user-friendly interface.

Developed for Web Engineering coursework using HTML5, CSS3, and JavaScript, the project demonstrates responsive design, DOM manipulation, input validation, and interactive website functionality.
🛠️ Technologies Used
- HTML5 – Website structure and content
- CSS3 – Styling, layout, and responsive design
- JavaScript – Interactive features, event handling, and form validation
✨ Features
- Home section introducing Campus Café
- Menu showcasing coffee, sandwiches, and cakes
- Menu filters for All, Drinks, and Pastries
- Price calculator showing selected items' total in Pakistani Rupees
- Light and dark theme toggle
- Special offers with expandable information
- Weekly opening hours table
- Contact form with input validation
- Age calculation based on birth year
- Character counter for special notes
- Responsive page layout
🚀 How to Use
1. Open the live website using the link below (once published).
2. Explore the Home, Menu, Special Offers, and Contact sections.
3. Filter the menu by All, Drinks, or Pastries.
4. Select menu items to calculate the total price.
5. Toggle between light and dark modes.
6. Read the special offer and weekly opening hours.
7. Fill out the contact form to try the interactive validation features.
💻 How to Run the Project Locally
1. Clone or download this repository.
2. Extract the ZIP file if you downloaded one.
3. Open the project folder.
4. Double-click index.html to open the website in your browser.
Note: Use a modern browser such as Google Chrome, Microsoft Edge, or Mozilla Firefox.
